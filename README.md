# 1. 뉴토끼 / 북토끼 / 마나토끼 웹소설 & 웹툰 다운로더

브라우저(유저스크립트) GUI와 Node.js CLI를 모두 지원하는 강력하고 편리한 다운로더입니다.

---

## ✨ 주요 기능 (소설 특화 및 GUI 업데이트)
- **🎨 모던 플로팅 GUI 패널**: 웹소설 목록 페이지 접속 시 우측 하단에 `📥 소설 다운로더` 런처가 자동으로 나타납니다.
- **🏷️ 작가명 및 1번째 장르 자동 추출**: 통합 파일명에 `[제목]-[작가명]-[1번째장르]`가 자동으로 조합되어 저장됩니다. (예: `중세의 방랑 마법사가 되었다-전최가-판타지.txt`)
- **🎯 유연한 범위 선택**: `전체 다운로드` 및 `시작/끝 회차 지정(일부 다운로드)` 지원.
- **📊 실시간 진행 상황**: 0%~100% 프로그레스 바 및 `전체 N개 중 n개 완료` 실시간 수치/로그 표시.
- **📁 로컬 저장 경로 지정**: File System Access API를 통해 내 컴퓨터의 원하는 저장 폴더를 직접 지정 가능.
- **🛡️ IP 차단 & 봇 탐지 회피**: 무작위 지터 딜레이, 백그라운드 절전 방지(Anti-Sleep), 신규 Shadow DOM 정밀 추출 및 문단 클렌징 탑재.

---

## 🚀 1. 유저스크립트 (Tampermonkey) 사용법
1. 브라우저에 **[Tampermonkey](https://www.tampermonkey.net/)** 확장 프로그램을 설치합니다.
2. `tokiDownloader.js` 스크립트를 Tampermonkey에 등록합니다.
3. 소설 목록 페이지(예: `https://newtoki1.org/novel/...` 또는 `https://booktoki.../novel/...`)에 접속합니다.
4. 화면 우측 하단의 **`📥 소설 다운로더`** 버튼을 클릭하여 패널을 엽니다.
5. 범위(전체 또는 일부), 저장 형식(통합 TXT / ZIP / EPUB), 저장 폴더를 선택한 뒤 **`▶ 다운로드 시작`**을 클릭합니다.

### 📄 생성되는 통합 소설 텍스트 구조
```text
================================================================
[ 소설 제목 ]
총 150화 수집 (1화 ~ 150화)
다운로드 일시: 2026-08-19 20:30
================================================================

[ 목차 ]
1화  언제 세상이 망한다고?
2화  우린 그런 셸터를 지어야 해
3화  이거 왜 이래?
4화  하나씩, 차근차근
...

================================================================


=== 1화 언제 세상이 망한다고? ===

[본문 내용...]


=== 2화 우린 그런 셸터를 지어야 해 ===

[본문 내용...]
```

## 💻 2. Node.js CLI 다운로더 사용법

### 준비 및 설치
```bash
git clone https://github.com/crossSiteKikyo/tokiDownloader.git
cd tokiDownloader
npm install
```

### 명령어 사용법
```bash
# 기본 사용법 (소설 전체 다운로드 및 목차 포함 통합 파일 자동 생성)
node down -url "https://newtoki1.org/novel/63587"

# 일부 회차만 다운로드 (예: 1화부터 50화까지)
node down -url "https://newtoki1.org/novel/63587" -start 1 -last 50

# 저장 경로 직접 지정
node down -url "https://newtoki1.org/novel/63587" -out "D:/MyNovels/EX급흡혈헌터"

# 화별 분할 파일로만 저장
node down -url "https://newtoki1.org/novel/63587" -split
```
