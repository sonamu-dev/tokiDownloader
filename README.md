# 📚 Toki Novel Downloader (GUI & CLI)

뉴토끼 및 북토끼 웹소설을 최적의 품질로 다운로드하고 통합 텍스트 파일로 자동 정제해 주는 프리미엄 다운로더입니다.

---

## 🚀 빠른 시작 (윈도우 앱 실행 방법)

### 방법 1. 마우스 더블클릭 실행 (가장 추천 ⭐)
- **`앱실행.vbs`** 더블클릭 ➜ 검은 콘솔 창 없이 **독립 윈도우 프로그램 창(주소창 없는 데스크톱 앱 형태)**으로 즉시 실행됩니다!
- **`실행하기.bat`** 더블클릭 ➜ 터미널 콘솔 로그와 함께 윈도우 프로그램 창이 실행됩니다.

> 💡 **Windows App Mode 지원**: 브라우저의 탭, 주소창(`http://...`), 뒤로가기 버튼이 완전히 제거된 **깔끔한 독립 윈도우 데스크톱 프로그램 형태**로 실행됩니다. 창을 닫으면 백그라운드 프로세스도 자동으로 완전히 종료됩니다.

### 방법 2. npm 명령어로 실행
```bash
npm start
# 또는
node gui.js
```

### 방법 3. Tampermonkey 브라우저 확장 프로그램
- `tokiDownloader.js` 스크립트를 Tampermonkey에 등록하면 웹소설 목록 페이지 우측 하단에 플로팅 GUI 버튼(`📥 소설 다운로더`)이 자동으로 나타납니다.

---

## ✨ 주요 기능
- **🎨 직관적인 독립 Web GUI 인터페이스**: URL 입력, 소설 정보 자동 조회(제목, 작가, 장르, 회차 수, 완결 배지), 범위 선택, 실시간 프로그레스 바(0~100%), 터미널 로그 제공.
- **🏷️ 작가명/장르/완결 여부 자동 감지 파일명**:
  - 완결작 전체 다운로드 시: `[제목]-[작가명]-[장르] [완결].txt`
  - 연재작 또는 일부 회차 다운로드 시: `[제목]-[작가명]-[장르] [1화~100화].txt`
- **📑 깔끔한 회차 구분**: 장식 문자(`===`) 없이 `1화  회차제목` 형태로 첫 머리부터 본문 시작.
- **🛡️ 차단 회피 엔진**: 지터 딜레이, Cloudflare Turnstile 자동 통과, Shadow DOM 정밀 추출 탑재.

## 🚀 1. 유저스크립트 (Tampermonkey) 사용법
1. 브라우저에 **[Tampermonkey](https://www.tampermonkey.net/)** 확장 프로그램을 설치합니다.
2. `tokiDownloader.js` 스크립트를 Tampermonkey에 등록합니다.
3. 소설 목록 페이지(예: `https://newtoki1.org/novel/...` 또는 `https://booktoki.../novel/...`)에 접속합니다.
4. 화면 우측 하단의 **`📥 소설 다운로더`** 버튼을 클릭하여 패널을 엽니다.
5. 범위(전체 또는 일부), 저장 형식(통합 TXT / ZIP / EPUB), 저장 폴더를 선택한 뒤 **`▶ 다운로드 시작`**을 클릭합니다.

### 📄 생성되는 통합 소설 텍스트 구조
```text
================================================================
[ 소설 제목 ]
총 150화 수집 (1화 ~ 150화)
다운로드 일시: 2026-08-19 20:30
================================================================

[ 목차 ]
1화  언제 세상이 망한다고?
2화  우린 그런 셸터를 지어야 해
3화  이거 왜 이래?
4화  하나씩, 차근차근
...

================================================================


=== 1화 언제 세상이 망한다고? ===

[본문 내용...]


=== 2화 우린 그런 셸터를 지어야 해 ===

[본문 내용...]
```

## 💻 2. Node.js CLI 다운로더 사용법

### 준비 및 설치
```bash
git clone https://github.com/crossSiteKikyo/tokiDownloader.git
cd tokiDownloader
npm install
```

### 명령어 사용법
```bash
# 기본 사용법 (소설 전체 다운로드 및 목차 포함 통합 파일 자동 생성)
node down -url "https://newtoki1.org/novel/63587"

# 일부 회차만 다운로드 (예: 1화부터 50화까지)
node down -url "https://newtoki1.org/novel/63587" -start 1 -last 50

# 저장 경로 직접 지정
node down -url "https://newtoki1.org/novel/63587" -out "D:/MyNovels/EX급흡혈헌터"

# 화별 분할 파일로만 저장
node down -url "https://newtoki1.org/novel/63587" -split
```
